
This is a simple weather forecast web app that shows the current weather and a 7-day forecast using the WeatherAPI.

## 📦 Features
- Shows **current weather** based on user input or location.
- Displays **7-day weather forecast**.
- **Saves recent searches** for quick access.
- Fully **responsive** (Works on Desktop, iPad, iPhone SE).

## 🛠 Technologies Used
- HTML5
- CSS3 
- JavaScript (fetch API)
- WeatherAPI


**Open `index.html` in a browser.**

## 🎯 How to Use
- Enter a **city name** and click "Get Forecast".
- Click **"Use My Location"** for automatic weather updates.
- **Recent searches** are saved for quick access.
- The **7-day forecast** appears below the current weather.
